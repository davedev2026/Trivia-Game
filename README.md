# Trivia Game 🎮

This is my first Python project — a simple trivia game I built after finishing my NECO exams.  
The game asks multiple-choice questions and keeps track of the player’s score.

## Features
- Multiple-choice questions
- Score tracking
- Beginner-friendly Python code

## Why I built it
I wanted to practice Python basics like loops, conditionals, and functions.  
This project helped me learn how to structure code and think logically.

## How to run
1. Download the file `Trivia Game.py`
2. Run it with Python 3:
   python "Trivia Game.py"
